Struct IntelContext 

Source 
pub struct IntelContext { /* private fields */ }
Expand description

Owning handle for the Vulkan compute context. Construct once per process and share via Arc; every operation borrows the shared state.

impl IntelContext

Source

pub fn new() -> Result<Arc<Self>>

Create a context on the first suitable Vulkan physical device. Returns the device whose vendor id is Intel’s (0x8086), unless UNIVERSAL_ENV is set in the environment — in which case the first Vulkan-capable device is accepted regardless of vendor.

Source

pub fn new_with_preference(universal: bool) -> Result<Arc<Self>>

universal = true accepts any Vulkan device; false restricts to Intel (vendor id 0x8086).
